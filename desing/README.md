# Материалы для разработки: лендинг «Личная CRM»

## Что внутри

| Файл | Зачем |
|---|---|
| `CLAUDE.md` | Инструкция для Claude Code: стек, структура, правила, критерии готовности |
| `docs/design-spec.md` | Токены, типографика, компоненты, адаптив по блокам |
| `docs/content.md` | Все тексты страницы по порядку |
| `reference/mobile.html` | Макет мобильной версии (390 px), открывается в браузере |
| `reference/desktop.html` | Макет десктопной версии (1440 px) |
| `starter/global.css` | Токены для Tailwind 4 (`@theme`) |
| `starter/favicon.svg` | Иконка сайта |

## Как запустить в Claude Code

1. Создайте пустую папку проекта и скопируйте туда содержимое этого архива.
2. Откройте папку в Claude Code и отправьте:

```
Собери лендинг по CLAUDE.md. Сначала создай проект Astro с Tailwind 4,
затем свёрстай блоки по порядку, сверяясь с reference/mobile.html и
reference/desktop.html. Тексты бери только из docs/content.md.
В конце запусти сборку и сравни страницу с макетами на 390 и 1440 px.
```

3. Перед публикацией укажите адрес приложения в `.env`:

```
PUBLIC_APP_URL=https://...
```
