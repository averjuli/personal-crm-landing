# Дизайн-спецификация

Стиль: светлый, «воздушный». Почти белый фон, белые карточки с тонкой рамкой, акцентные элементы обведены чёрной линией 1,5 px, лаймовые плашки-маркеры. Визуал должен показывать, что приложением пользоваться легче лёгкого.

Точные значения смотри в `reference/mobile.html` (390 px) и `reference/desktop.html` (1440 px).

## Токены

### Цвета

| Токен | Hex | Где |
|---|---|---|
| `bg` | `#FAFAF7` | фон страницы, фон карточки контакта |
| `surface` | `#FFFFFF` | карточки, полоса блока «Решение» |
| `surface-muted` | `#F1F1EC` | подложка иллюстрации «Проблема» |
| `avatar-muted` | `#E4E4DE` | аватар «?» |
| `ink` | `#111111` | основной текст, рамки 1,5 px, тёмные блоки |
| `text-2` | `#55554F` | подзаголовки и абзацы |
| `text-3` | `#77776F` | подписи полей |
| `line` | `#ECECE6` | тонкие рамки 1 px, разделители блоков |
| `line-dashed` | `#B9B9B1` | пунктир плашек «чаты / заметки / память» |
| `accent` | `#D4F25A` | лайм: кнопки, плашки-маркеры, иконки, логотип |
| `on-dark-2` | `#C9C9C2` | абзац в тёмном блоке |
| `on-dark-line` | `#2A2A28` | разделитель в тёмном блоке |

### Шрифты

- Display: **Unbounded** 500 (заголовки), 600 (логотип, цифры шагов, инициалы)
- Body: **Manrope** 400 / 500 / 600 / 700
- Обязательно с кириллицей. `letter-spacing` у заголовков отрицательный (см. шкалу).

### Радиусы

`14` поля в карточке контакта, иконки 48 px · `18 / 20` кнопки, поля формы · `22 / 24` карточки шагов и выгод · `28` крупные карточки на десктопе · `32 / 40` финальный тёмный блок · `999` метки и плашки.

### Сетка и отступы

- Контейнер: `max-w-[1200px] mx-auto`, боковые поля 24 px (мобильная) / 40 px (десктоп).
- Вертикальные отступы блоков: 56 px / 112 px.
- Разделители между блоками: `border-t` 1 px `line`. Блок «Решение» — полоса во всю ширину на `surface` с рамками сверху и снизу.
- Брейкпоинт смены раскладки: `lg` (1024 px). Для выгод на `md` — 2 колонки.

## Компоненты

- **Button primary**: фон `accent`, текст `ink`, рамка 1,5 px `ink`, иконка arrow-right 18–20 px. Мобильная: высота 58, на всю ширину, радиус 18. Десктоп: высота 64, `px-8`, по ширине текста, радиус 20. В тёмном блоке — без рамки.
- **Button outline** (только шапка, ≥ lg): высота 48, `px-[22px]`, рамка 1,5 px `ink`, радиус 14.
- **Chip** (метка блока): `px-3 py-1.5` (дес. `px-3.5 py-2`), радиус 999, рамка 1,5 px `ink`. Вариант `accent` — с лаймовым фоном (только «Как это устроено»).
- **Маркер-выделение** в заголовках: `bg-accent rounded-[10px] px-1.5` (дес. `rounded-2xl px-2.5`); в тёмном блоке текст внутри маркера `ink`.
- **Логотип**: круг 26 / 30 px, `accent` + рамка 1,5 px `ink`, рядом «Личная CRM».
- **Иконки**: inline SVG, stroke 2, `stroke-linecap: round`. Нужны: user, check, search, monitor, arrow-right. Сами SVG-пути — в reference-файлах.

## Блоки и адаптив

### Шапка
- Мобильная: только логотип, высота 44, `pt-5`.
- Десктоп: логотип слева, outline-кнопка справа, `py-6`.

### 1. Первый экран
- Мобильная: занимает один экран (`min-h-svh`, колонка, gap 26): шапка → H1 + лид → иллюстрация (растягивается, `flex-1`, по центру) → кнопка внизу. **Кнопка идёт после иллюстрации.**
- Десктоп: две колонки (`gap-16`): слева H1, лид (max-w 520), кнопка; справа иллюстрация (max-w 460). Отступы `pt-[72px] pb-[120px]`.
- Иллюстрация: три поля-карточки (белые, рамка 1 px `line`, у третьего — рамка 1,5 px `ink` и статичный «курсор»: вертикальная черта 1,5 px после текста), подпись 12 / 13 px `text-3`, значение 16 / 18 px 600. Под ними справа — тёмная пилюля «✓ Сохранено» с лаймовой галочкой.

### 2. Проблема
- Мобильная: колонка — метка, H2, абзац, иллюстрация.
- Десктоп: текст слева, иллюстрация справа (max-w 460), по центру по вертикали.
- Иллюстрация: подложка `surface-muted`, радиус 24 / 28; внутри белая строка контакта (аватар «?» 40 / 48 px на `avatar-muted`) и ряд пунктирных плашек.

### 3. Решение
- Верх: текст + карточка контакта (рамка 1,5 px `ink`, фон `bg`, аватар-инициалы на `accent`). Мобильная — колонкой, десктоп — в две колонки.
- Шаги: мобильная — список строк (кружок 40 px + текст); десктоп — три карточки в ряд (фон `bg`, рамка `line`, радиус 22). Кружок третьего шага залит `accent`.
- Плашка: фон `ink`, радиус 24 / 28, текст белый, «лично» цветом `accent`.

### 4. Выгоды
- Метка, затем 4 карточки: 1 колонка → 2 (md) → 4 (lg). Белые, рамка `line`, радиус 22 / 24. Иконка в лаймовом квадрате 40 / 48 px (радиус 12 / 14), между иконкой и текстом 14 / 40 px.

### 5. Призыв к действию
- Тёмный блок `ink`, радиус 32 / 40. Мобильная: отступ 12 px от краёв экрана, `px-6 pt-11 pb-8`. Десктоп: внутри контейнера, `px-16 pt-20 pb-10`.
- H2 с маркером «сегодня», абзац `on-dark-2`, лаймовая кнопка без рамки, ниже подвал: разделитель `on-dark-line` (десктоп) и логотип.
